# USB 매체제어 (윈도우, 소규모 사무실용)

허용 목록에 등록한 USB만 쓸 수 있게 하고, 나머지는 막고, 모든 기록을 한곳에 모으는 도구입니다.
ISMS 보조저장매체 관리 항목에서 요구하는 승인·관리대장·기록·점검 증빙을 관리 화면에서 바로 뽑을 수 있게 만들었습니다.

```
 [직원 PC 1] ─┐
 [직원 PC 2] ─┼─ 30초마다 기록 전송 / 최신 허용 목록 받기 ──▶ [관리 서버 PC]  ◀── 관리자는 웹 브라우저로 접속
 [직원 PC N] ─┘                                              (상시 켜 둠)
```

| 폴더 | 내용 |
|---|---|
| `server/` | 관리 서버 (자바). 웹 관리 화면 + 데이터 저장 |
| `server/windows/` | 서버 PC 설치 스크립트 |
| `agent/` | 직원 PC에 설치하는 감시 프로그램 |

## 1. 관리 서버 설치 (상시 켜 두는 PC 1대)

1. **실행 파일 만들기** (개발 PC에서 한 번)
   ```
   cd usb-control/server
   mvn package
   ```
   `target/usb-control-server.jar` 가 생깁니다. 이 파일을 `server/windows` 폴더에 복사합니다.
2. **서버 PC에 자바 21 이상 설치** (예: Eclipse Temurin 21)
3. `server/windows` 폴더를 서버 PC로 복사하고 `install-server.cmd` 를 더블클릭합니다.
   - `C:\UsbControlServer` 에 설치되고, 컴퓨터가 켜지면 자동으로 실행됩니다.
   - 방화벽에서 8080 포트를 사내망에만 엽니다.
   - 끝나면 관리 화면 주소(예: `http://192.168.0.10:8080`)가 표시됩니다.
4. 브라우저로 관리 화면에 들어가 **첫 관리자 계정**을 만듭니다.
5. **설정** 화면에서 **PC 프로그램 접속 키**를 확인합니다. 직원 PC에 설치할 때 씁니다.

서버 PC의 IP가 바뀌면 직원 PC들이 연결하지 못하므로, 공유기에서 서버 PC의 IP를 고정해 두세요.

## 2. 직원 PC에 감시 프로그램 설치 (PC마다)

1. `agent` 폴더를 직원 PC로 복사합니다.
2. `install.cmd` 를 더블클릭합니다. (관리자 권한 확인 창에서 '예')
3. 서버 주소(예: `192.168.0.10:8080`)와 접속 키를 입력합니다.
4. 1분 안에 관리 화면의 **PC 적용 현황**에 그 PC가 나타나면 완료입니다.

설치하는 순간부터 **허용 목록에 없는 USB 저장장치와 휴대폰 파일 전송은 모두 막힙니다.**
키보드, 마우스, 프린터 같은 저장장치가 아닌 USB 장치는 막지 않습니다. (키보드·마우스는 지정 포트를 정하면 빠짐/바뀜을 기록합니다. 3장 참고)

이미 설치한 PC에 새 버전을 넣을 때도 같은 방법으로 `install.cmd` 를 다시 실행하면 됩니다.

## 3. 평소 사용

**직원이 USB를 쓰고 싶을 때**
1. 직원이 USB를 꽂으면 막히고, 화면에 "허용되지 않은 USB를 차단했습니다" 알림이 뜹니다.
2. 직원이 사용 신청을 합니다. (회사 신청 양식, 메일 등)
3. 관리자가 관리 화면 **현황** 또는 **사용 기록**에서 그 차단 기록의 **[허용 등록]** 을 누릅니다.
   장치 ID가 자동으로 채워지고, 사용자, 부서, 사용 목적, 승인자, 만료일을 입력해 등록합니다.
4. 30초 안에 그 직원 PC에서 USB가 열립니다.

**다 쓰면** 허용 매체 화면에서 **회수**(사유 입력)합니다. 만료일을 넣어 두면 그 다음 날부터 자동으로 막힙니다.

**한 달에 한 번** **정기 점검** 화면에서 지난달 기록을 보고 점검 결과를 남깁니다. 30일이 지나면 현황 화면에 알림이 뜹니다.

**키보드·마우스 지정 포트** (PC마다 한 번)

키보드·마우스를 꽂아 둘 USB 포트를 정해 두면, 거기서 빠지거나 다른 장치로 바뀌는 것을 기록합니다.
키보드 선 중간에 끼우는 키 입력 기록 장치나, 키보드로 위장한 USB(BadUSB)를 찾아내는 데 씁니다.

1. 직원 PC에 원래 쓰는 키보드·마우스만 정해진 포트에 꽂혀 있는지 확인합니다.
2. 관리 화면 **PC 적용 현황**에서 PC 이름을 누르고 **[지금 꽂혀 있는 포트를 모두 지정]** 을 누릅니다.
3. 30초 안에 그 PC에 적용됩니다. 이후 아래와 같이 기록되고, 현황 화면에 빨간색으로 표시됩니다.

| 기록 | 언제 |
|---|---|
| 빠짐 | 지정 포트에서 키보드·마우스가 4초 넘게 빠져 있을 때 (잠깐 끊겼다 붙는 것은 기록 안 함) |
| 다른 장치로 바뀜 | 지정 포트에 처음 지정한 것과 다른 키보드·마우스가 꽂혔을 때 |
| 지정 외 포트에 연결 | 지정하지 않은 포트에 키보드·마우스가 꽂혔을 때 |
| 다시 연결 / 지정 외 포트에서 빠짐 | 원래대로 돌아왔을 때 (참고용, 회색) |

**사용 기록** 화면에서 구분을 '키보드·마우스 포트'로 고르면 이 기록만 볼 수 있고, 엑셀에는 포트 칸이 함께 나옵니다.
키보드·마우스를 바꿔 주었으면 PC 화면에서 **[지금 장치로 다시 지정]** 을 누르세요.
USB로 연결된 것만 확인합니다. 노트북 내장 키보드·터치패드와 블루투스 장치는 확인하지 않습니다.
기록만 하고 막지는 않습니다. (키보드를 막으면 직원이 PC를 쓸 수 없게 될 수 있어서입니다.)

**개인정보처리 PC** (개인정보를 다루는 PC마다 한 번)

인사·급여·고객 정보를 다루는 PC는 다른 PC보다 엄격하게 막습니다. (개인정보의 안전성 확보조치 기준의 보조저장매체 반출·입 통제)

1. 관리 화면 **PC 적용 현황**에서 PC 이름을 누르고, **개인정보처리자**(이 PC를 쓰는 사람)를 입력한 뒤 **[개인정보처리 PC로 지정]** 을 누릅니다.
2. 30초 안에 그 PC에 아래가 적용됩니다.

| 무엇이 달라지나 | 내용 |
|---|---|
| 허용 매체 | **적용 PC를 이 PC로 골라 등록한 매체만** 열립니다. '전체 PC'로 등록한 매체와 별표(*) 줄은 이 PC에서 막힙니다. |
| 읽기 전용 | 허용 매체도 **읽기 전용**으로 열립니다. 매체 등록 때 **'개인정보처리 PC에서 쓰기(반출) 허용'** 을 체크한 매체만 쓸 수 있습니다. 휴대폰, CD/DVD도 같습니다. |
| 파일 반출 기록 | 허용 USB로 복사한 **파일 이름과 크기**가 사용 기록에 '파일 반출'로 남습니다. 현황 화면에도 최근 반출이 나옵니다. |
| 사용 기간 | 이 PC용 매체는 **만료일이 꼭 있어야** 하고 등록일(수정일)부터 **30일**을 넘길 수 없습니다. |
| 정기 점검 | 점검 화면에 개인정보처리 PC의 차단/허용/반출 건수가 따로 나오고 점검 기록에 같이 남습니다. |

- 반출이 필요하면: 직원이 신청 → 관리자가 **새 매체 등록**에서 적용 PC를 그 PC로, 만료일을 짧게, 쓰기 허용을 체크해 등록 → 다 쓰면 **회수**.
  사용 목적 칸에 무엇을 어디로 보내는지 적어 두면 점검 때 반출 기록과 맞춰 보기 쉽습니다.
- 쓰기 허용 매체는 **혼자 꽂혀 있을 때만** 쓸 수 있습니다. 쓰기 허용이 아닌 매체를 같이 꽂으면 둘 다 읽기 전용이 됩니다.
  읽기 전용과 쓰기 사이를 바꿀 때 프로그램이 USB를 잠깐 끊었다 다시 연결합니다.
- 파일 반출은 USB 저장장치만 기록합니다. 휴대폰은 파일 이름을 알 수 없으므로 개인정보처리 PC에서는 휴대폰에 쓰기 허용을 주지 마세요.
- 한꺼번에 아주 많은 파일을 복사하면 일부를 놓칠 수 있고, 이때는 '파일 반출 기록 누락'이 빨간색으로 남습니다.
- PC 프로그램 2.2.0 이상이 필요합니다. 예전 버전이면 PC 적용 현황에 'PC 프로그램 업데이트 필요'가 빨간색으로 뜹니다. `install.cmd` 를 다시 실행하세요.

## 4. ISMS 심사 때 보여줄 것

| 심사원이 묻는 것 | 보여줄 화면 / 내려받을 파일 |
|---|---|
| 보조저장매체 관리대장 | 허용 매체 → **관리대장 엑셀 내려받기** (사용자, 부서, 목적, 승인자, 등록일, 만료일, 회수일·사유) |
| 등록된 매체만 쓰는지 | 직원 PC에 미등록 USB를 꽂아 차단되는 것을 시연 |
| 누가 승인했는지 | 관리대장의 승인자 칸 + 관리 이력의 '허용 매체 등록' 기록 (등록한 관리자, 시간, 내용) |
| 사용·차단 기록 | 사용 기록 → **엑셀 내려받기** (시간, PC, 사용자, 허용/차단, 매체) |
| 정기적으로 검토하는지 | 정기 점검 → **엑셀 내려받기** (점검일, 점검자, 기간, 건수, 결과, 내용) |
| 전 PC에 적용됐는지 | PC 적용 현황 (모든 PC가 '정상'이고 최신 정책 적용) |
| 보안 시스템 접근 통제 | 관리자 개인별 계정, 비밀번호 규칙, 5회 실패 시 잠금, 30분 자동 로그아웃 |
| 정책 변경 이력 | 관리 이력 → **엑셀 내려받기** (로그인, 등록/수정/회수, 설정 변경, 내려받기까지 모두 기록) |
| 키보드·마우스 포트 이상 | 사용 기록 → 구분 '키보드·마우스 포트' → **엑셀 내려받기** (빠짐, 바뀜, 지정 외 포트 연결) |
| 개인정보처리 PC가 어느 것인지 | PC 적용 현황 → **PC 목록 엑셀 내려받기** (구분, 개인정보처리자, 지정일, 지정 관리자) |
| 개인정보처리 PC의 매체 반출 통제 | 관리대장의 '개인정보처리 PC', '쓰기' 칸 + 직원 PC에서 미등록 USB 차단·허용 USB 쓰기 금지 시연 |
| 개인정보 파일 반출 기록 | 사용 기록 → 구분 '파일 반출' + '개인정보처리 PC만' → **엑셀 내려받기** (시간, PC, 사용자, 매체, 파일, 크기) |
| 감시 프로그램을 끈 적 없는지 | 사용 기록의 '프로그램 설치/제거', PC 적용 현황의 마지막 연결 시간 |
| 백업 | 설정 → 백업 (매일 새벽 자동, 60개 보관) |

프로그램과 별개로 **보조저장매체 관리 지침**(사용 원칙, 신청·승인 절차, 점검 주기)과 **사용 신청서** 양식은 회사 문서로 준비해야 합니다.

## 5. 설정 화면에서 바꿀 수 있는 것

| 설정 | 기본 | 설명 |
|---|---|---|
| 휴대폰 파일 전송도 막기 | 켬 | 허용 매체에 등록한 휴대폰만 연결. 충전은 계속 됨 |
| 차단 알림창 | 켬 | 윈도우 Home 버전에서는 안 뜸 |
| 설치 단계 차단 | 끔 | **켜는 것을 권장.** 윈도우 정책으로 미등록 USB의 설치 자체를 막아 꽂는 순간부터 빈틈이 없음. 끄면 꽂은 뒤 최대 2초 동안 열릴 수 있음. 윈도우 10 2004 이상 필요. 켜면 가상 디스크(VHD) 연결과 새 내장 디스크 추가도 막힘 |

## 6. 꼭 알아둘 점

- **직원 계정이 PC 관리자 권한을 가지고 있으면 감시 프로그램을 지울 수 있습니다.** 직원 계정은 '표준 사용자'로 두세요.
  표준 사용자는 감시 프로그램을 끄거나 설정을 고칠 수 없습니다. 지워지더라도 서버에 '프로그램 제거' 기록이 남거나,
  PC 적용 현황에서 '7일 넘게 연결 없음'으로 드러납니다.
- 서버가 꺼져 있어도 직원 PC는 **마지막으로 받은 허용 목록으로 계속 막고**, 기록은 모아 두었다가 서버가 켜지면 보냅니다.
  서버에 한 번도 연결하지 못한 PC는 모든 USB를 막습니다.
- 서버와 PC는 사내망에서 암호화하지 않은 HTTP로 통신합니다. 사내망 밖으로 서버를 열지 마세요.
- 서버 PC가 고장 나면 백업도 같이 사라지므로 `C:\UsbControlServer\backup` 폴더를 가끔 다른 저장소에 복사해 두세요.
- 직원 PC의 감시 프로그램은 실제 윈도우 PC에서 한 번 시험해 본 뒤 전체에 까세요.
  특히 개인정보처리 PC는 지정한 뒤 ① 허용 USB에 파일을 저장하면 막히는지 ② 쓰기 허용 매체에 복사하면 사용 기록에 '파일 반출'이 남는지 확인하세요.
- 개인정보처리 PC의 읽기 전용은 윈도우 '이동식 저장소 액세스' 정책(쓰기 권한 거부)을 씁니다.
  회사에서 그룹 정책으로 같은 설정을 이미 쓰고 있으면, 지정을 해제해도 그 설정은 건드리지 않습니다.

## 7. 제거

- 직원 PC: `agent/uninstall.cmd` (막아 둔 장치와 개인정보처리 PC의 읽기 전용도 다시 풀림. 서버에 제거 기록이 남음)
- 서버 PC: `server/windows/uninstall-server.cmd` (데이터는 남음)
