# USB 매체제어 (윈도우)

허용 목록에 등록한 USB만 쓸 수 있게 하고, 나머지는 막는 도구입니다.
막는 방법은 두 가지이고, 허용 목록 파일은 둘이 같이 씁니다.

| | 프로그램 방식 | 정책 방식 |
|---|---|---|
| 동작 | 2초마다 확인해서 미등록 장치를 '사용 안 함'으로 바꿈 | 윈도우가 미등록 디스크의 설치 자체를 거부 |
| 막는 것 | USB 메모리, 외장하드, 카드리더, USB DVD, **휴대폰 파일 전송** | USB 메모리, 외장하드, 카드리더 |
| 사용 기록 | 남음 (언제, 누가, 어떤 장치, 허용/차단) | 안 남음 |
| 차단 알림창 | 뜸 (Home 버전은 안 뜸) | 윈도우 기본 알림만 |
| 빈틈 | 꽂은 뒤 최대 2초 동안은 열릴 수 있음 | 없음 |
| 필요한 윈도우 | 윈도우 10 / 11 | 윈도우 10 2004 이상 / 11 |

둘 다 켜도 됩니다. 정책 방식으로 확실히 막고, 프로그램 방식으로 기록과 휴대폰 차단을 더하는 식입니다.

## 쓰는 법

1. 이 `usb-control` 폴더를 통째로 윈도우 PC에 복사합니다.
2. `usb-control.cmd` 를 더블클릭합니다. (관리자 권한 확인 창에서 '예')
3. 메뉴가 뜨면:
   - **허용할 USB를 먼저 꽂고 1번** → 번호를 골라 허용 목록에 넣습니다.
   - **4번**(프로그램 방식) 또는 **6번**(정책 방식)으로 차단을 켭니다.
4. 나중에 USB를 추가로 허용할 때도 꽂은 뒤 1번으로 등록합니다.
   정책 방식이면 등록 후 6번을 한 번 더 실행해야 반영됩니다.

순서를 반대로 해서 차단을 먼저 켜도 괜찮습니다. 막힌 USB도 1번 목록에 '차단됨'으로 나오니 거기서 등록하면 됩니다.

## 파일 위치

| 파일 | 내용 |
|---|---|
| `C:\ProgramData\UsbControl\allowlist.txt` | 허용 목록. 메뉴 2번으로 메모장에서 직접 고칠 수 있음 |
| `C:\ProgramData\UsbControl\logs\usb-log.csv` | 사용 기록. 엑셀로 열림. 메뉴 3번으로도 볼 수 있음 |
| `C:\ProgramData\UsbControl\logs\error.log` | 프로그램 오류 기록 |

## 스크립트 없이 정책만 손으로 켜는 법

윈도우 Pro 이상이면 그룹 정책 편집기에서 직접 설정할 수 있습니다. 메뉴 6번이 하는 일과 같습니다.

1. `Win + R` → `gpedit.msc`
2. **컴퓨터 구성 → 관리 템플릿 → 시스템 → 장치 설치 → 장치 설치 제한**
3. 아래 세 항목을 **사용**으로 바꿉니다. (윈도우 버전에 따라 이름이 조금 다를 수 있습니다)
   - **모든 장치 일치 조건에 대해 허용 및 금지 정책의 계층적 평가 순서 적용**
   - **이 장치 설치 클래스와 일치하는 드라이버를 사용하는 장치 설치 금지**
     → 표시 단추를 눌러 `{4d36e967-e325-11ce-bfc1-08002be10318}` 입력 (디스크 드라이브 종류)
     → '이미 설치된 일치하는 장치에도 적용' 은 **절대 체크하지 마세요.** 내장 디스크까지 지워집니다.
   - **이 장치 인스턴스 ID와 일치하는 장치 설치 허용**
     → 표시 단추를 눌러 허용할 USB의 장치 ID 입력 (메뉴 1번에서 회색 글씨로 나오는 값)
4. 정책은 **처음 꽂는 USB**에만 걸립니다. 예전에 꽂아 본 USB는 장치 관리자 → 보기 → 숨겨진 장치 표시 →
   디스크 드라이브에서 해당 USB를 '디바이스 제거' 해야 막힙니다. (메뉴 6번은 이것까지 자동으로 합니다)

회사에서 도메인(Active Directory)을 쓰면 같은 설정을 그룹 정책으로 내려보내면 모든 PC에 한꺼번에 적용됩니다.

## 알아둘 점

- **사용자가 관리자 권한을 가지고 있으면 풀 수 있습니다.** 실제로 쓰려면 사용자 계정은 '표준 사용자'로 두세요.
  표준 사용자는 감시 프로그램을 끌 수도, 허용 목록을 고칠 수도 없습니다.
- 정책 방식은 새 디스크 설치를 막으므로, 가상 디스크(VHD) 연결이나 새 내장 디스크 추가도 같이 막힙니다.
  그럴 때는 7번으로 잠깐 해제했다가 다시 켜세요.
- USB 키보드, 마우스, 프린터 같은 저장장치가 아닌 장치는 건드리지 않습니다.
- 막는 것은 '연결' 단위입니다. 허용된 USB에서는 읽기/쓰기가 모두 됩니다. (읽기 전용, 파일 복사 기록은 3단계 기능)

## 끄기

- 프로그램 방식: 메뉴 5번 (막아 둔 장치도 다시 풀립니다)
- 정책 방식: 메뉴 7번
