개인정보 검출

각 PC에 저장된 파일에 개인정보가 들어 있는지 주기적으로 검사합니다. 결과는 개인정보 검출 화면에서 봅니다. 검사는 PC가 켜져 있을 때 낮은 우선순위로 돌아서 일하는 데 큰 지장은 없습니다.

PC 프로그램 접속 키

각 PC에 감시 프로그램을 설치할 때 이 키를 입력합니다. 다른 사람에게 알려주지 마세요.

관리자 추가

백업

매일 새벽 2시 30분에 자동으로 백업합니다. 최근 60개만 남기고 오래된 것은 지웁니다.
백업 폴더:

서버 PC가 고장 나면 백업도 같이 사라지므로, 이 폴더를 가끔 다른 곳(외장 저장소 등)에도 복사해 두세요.

아직 백업이 없습니다.
